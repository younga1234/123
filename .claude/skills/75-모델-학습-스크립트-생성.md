# 모델 학습 스크립트 생성

머신러닝 모델 학습 코드를 생성합니다.

## 사용 방법
모델 유형과 데이터를 제공하면, 학습 스크립트를 생성합니다.

## 주요 기능
- TensorFlow, PyTorch
- 하이퍼파라미터 튜닝
- 교차 검증
- 조기 종료
