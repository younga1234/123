# 코드 자동 완성

작성 중인 코드를 분석하여 다음에 올 코드를 자동으로 완성합니다.

## 사용 방법
작성 중인 코드를 제공하면, 문맥을 파악하여 다음 코드를 제안합니다.

## 주요 기능
- 함수 본문 자동 완성
- 반복 패턴 감지
- import/require 문 자동 완성
- 타입 정의 자동 완성
