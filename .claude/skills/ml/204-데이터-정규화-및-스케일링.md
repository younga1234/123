# 데이터 정규화 및 스케일링

**카테고리**: 데이터 전처리

StandardScaler, MinMaxScaler, RobustScaler 등으로 데이터를 정규화합니다.

## 💻 실행 가능한 코드

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler
import pandas as pd
```
