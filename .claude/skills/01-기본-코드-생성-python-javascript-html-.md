# 기본 코드 생성 (Python, JavaScript, HTML 등)

사용자가 요청한 프로그래밍 언어로 기본 코드를 생성합니다.

## 사용 방법
언어와 코드 목적을 설명하면, 해당 언어로 코드를 자동 생성합니다.

## 주요 기능
- Python, JavaScript, TypeScript 지원
- HTML/CSS, Java, C++, Go, Rust 지원
- PHP, Ruby 등 다양한 언어
- 기본 템플릿 제공
