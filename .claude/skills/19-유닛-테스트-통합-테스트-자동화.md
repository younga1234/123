# 유닛 테스트/통합 테스트 자동화

테스트 실행을 자동화하고 결과를 리포트합니다.

## 사용 방법
테스트 실행 명령을 설정하면, 자동으로 테스트를 실행합니다.

## 주요 기능
- Jest, Mocha, Pytest 지원
- 커버리지 리포트
- 실패 케이스 분석
- 성능 테스트
