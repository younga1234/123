# 디버깅 도우미

코드의 버그를 찾고 수정하는 과정을 도와줍니다.

## 사용 방법
버그가 있는 코드와 예상 동작을 설명하면, 문제를 찾아 해결책을 제시합니다.

## 주요 기능
- 로그 출력 위치 제안
- 브레이크포인트 설정
- 변수 값 추적
- 엣지 케이스 확인
