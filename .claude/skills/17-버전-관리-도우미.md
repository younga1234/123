# 버전 관리 도우미

프로젝트 버전 관리를 자동화합니다.

## 사용 방법
버전 업데이트 규칙을 설정하면, 자동으로 버전을 관리합니다.

## 주요 기능
- Semantic Versioning
- CHANGELOG 자동 생성
- 태그 자동 생성
- 릴리스 노트 작성
