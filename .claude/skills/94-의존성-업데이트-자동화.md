# 의존성 업데이트 자동화

프로젝트 의존성을 자동으로 업데이트합니다.

## 사용 방법
업데이트 정책을 설정하면, 자동으로 의존성을 업데이트합니다.

## 주요 기능
- Dependabot, Renovate
- 보안 패치
- 호환성 검사
- 자동 PR 생성
