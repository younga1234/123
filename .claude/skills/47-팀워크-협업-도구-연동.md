# 팀워크 협업 도구 연동

Slack, Teams 등 협업 도구와 연동합니다.

## 사용 방법
협업 도구 API를 통해 알림과 자동화를 설정합니다.

## 주요 기능
- Slack 봇 생성
- 알림 자동화
- 명령어 시스템
- 통합 대시보드
