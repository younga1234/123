# Git 명령어 자동 생성

Git 작업을 위한 적절한 명령어를 자동으로 생성합니다.

## 사용 방법
수행하려는 Git 작업을 설명하면, 필요한 명령어를 제시합니다.

## 주요 기능
- commit, branch, merge 명령어
- 충돌 해결 가이드
- stash, rebase 명령어
- 안전한 명령어 추천
