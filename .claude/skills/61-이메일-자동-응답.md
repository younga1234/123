# 이메일 자동 응답

이메일 자동 응답 시스템을 구축합니다.

## 사용 방법
응답 규칙을 설정하면, 자동으로 이메일에 응답합니다.

## 주요 기능
- 템플릿 기반 응답
- 조건부 응답
- 첨부 파일 처리
- SMTP 통합
