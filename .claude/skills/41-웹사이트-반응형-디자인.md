# 웹사이트 반응형 디자인

모바일, 태블릿, 데스크톱에 대응하는 반응형 디자인을 구현합니다.

## 사용 방법
기존 디자인을 반응형으로 변환하거나 새로 제작합니다.

## 주요 기능
- 미디어 쿼리
- 플렉스박스/그리드
- 모바일 퍼스트
- 터치 최적화
