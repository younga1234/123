# GitHub 통합

GitHub 저장소와의 통합 작업을 자동화합니다.

## 사용 방법
GitHub 작업을 요청하면, API를 통해 자동으로 수행합니다.

## 주요 기능
- PR 생성/관리
- Issue 관리
- Branch 보호 설정
- Webhook 설정

## 사용 예시
이 skill을 사용하려면 Claude에게 관련 작업을 요청하세요.

예: "GitHub 통합 도와줘"
