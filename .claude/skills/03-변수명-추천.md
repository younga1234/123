# 변수명 추천

코드의 목적과 문맥에 맞는 의미 있는 변수명을 추천합니다.

## 사용 방법
변수가 담을 값이나 목적을 설명하면, 적절한 변수명을 제안합니다.

## 주요 기능
- camelCase, snake_case 지원
- PascalCase (클래스명)
- UPPER_SNAKE_CASE (상수)
- 명확하고 일관된 네이밍
