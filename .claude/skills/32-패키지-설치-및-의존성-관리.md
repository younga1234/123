# 패키지 설치 및 의존성 관리

프로젝트 의존성을 관리하고 최적화합니다.

## 사용 방법
의존성을 분석하고 업데이트를 제안합니다.

## 주요 기능
- npm, pip, yarn 지원
- 버전 충돌 해결
- 보안 취약점 스캔
- 불필요한 패키지 제거
