# 클라우드 배포 자동화

AWS, GCP, Azure 등 클라우드에 자동 배포합니다.

## 사용 방법
배포 설정을 제공하면, 자동 배포 파이프라인을 구축합니다.

## 주요 기능
- 인프라 as 코드
- 자동 스케일링
- 로드 밸런싱
- 헬스 체크
