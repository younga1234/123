# 코드 스타일 가이드 자동 적용

## 사용 방법
스타일 가이드를 선택하면, 코드를 자동으로 포맷팅합니다.

## 주요 기능
- Prettier, ESLint 설정
- Google, Airbnb 스타일
- 자동 포맷팅
- 커밋 훅 설정
