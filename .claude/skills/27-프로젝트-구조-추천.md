# 프로젝트 구조 추천

프로젝트 유형에 맞는 디렉토리 구조를 추천합니다.

## 사용 방법
프로젝트 유형을 설명하면, 적절한 구조를 제안합니다.

## 주요 기능
- MVC, MVVM 패턴
- 모듈화 전략
- 설정 파일 위치
- 테스트 디렉토리 구조
