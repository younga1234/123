# 주석 자동 삽입

코드의 복잡한 부분이나 중요한 로직에 자동으로 주석을 추가합니다.

## 사용 방법
코드를 제공하면, 자동으로 적절한 위치에 설명 주석을 삽입합니다.

## 주요 기능
- 함수 docstring/JSDoc
- 인라인 주석
- TODO/FIXME 마커
- 파라미터 및 반환값 설명
