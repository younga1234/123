# 함수명 추천

함수의 동작과 목적에 맞는 명확한 함수명을 추천합니다.

## 사용 방법
함수가 수행할 작업을 설명하면, 적절한 함수명을 제안합니다.

## 주요 기능
- get/set, create/update/delete
- calculate/compute, validate/verify
- parse/format, handle/process
- 동사로 시작하는 명확한 이름

## 사용 예시
이 skill을 사용하려면 Claude에게 관련 작업을 요청하세요.

예: "함수명 추천 도와줘"
