# 데이터 마이그레이션

데이터를 다른 시스템으로 마이그레이션합니다.

## 사용 방법
소스와 타겟 시스템을 지정하면, 마이그레이션을 수행합니다.

## 주요 기능
- 스키마 변환
- 데이터 검증
- 중복 제거
- 롤백 지원
