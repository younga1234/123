# 시계열 예측

시계열 데이터의 미래 값을 예측합니다.

## 사용 방법
시계열 데이터를 제공하면, 예측 모델을 생성합니다.

## 주요 기능
- ARIMA, Prophet
- LSTM, GRU
- 계절성 분석
- 신뢰 구간
