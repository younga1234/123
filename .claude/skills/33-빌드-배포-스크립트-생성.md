# 빌드/배포 스크립트 생성

프로젝트 빌드 및 배포 스크립트를 생성합니다.

## 사용 방법
배포 환경 정보를 제공하면, 스크립트를 생성합니다.

## 주요 기능
- 빌드 자동화
- 배포 자동화
- 롤백 스크립트
- 환경별 설정

## 사용 예시
이 skill을 사용하려면 Claude에게 관련 작업을 요청하세요.

예: "빌드/배포 스크립트 생성 도와줘"
