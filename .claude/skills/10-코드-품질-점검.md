# 코드 품질 점검

코드의 전반적인 품질을 평가하고 개선점을 제시합니다.

## 사용 방법
점검할 코드나 프로젝트를 제공하면, 품질 점수와 개선 방안을 제시합니다.

## 주요 기능
- 복잡도 분석
- 중복 코드 검사
- 네이밍 컨벤션 검사
- 보안 이슈 스캔
