# GIF/동영상 생성

코드로 GIF나 동영상을 생성합니다.

## 사용 방법
생성할 미디어를 설명하면, 생성 스크립트를 제공합니다.

## 주요 기능
- FFmpeg 통합
- 캔버스 녹화
- 스크린샷 캡처
- 자동 인코딩
