# 오류 알림

시스템 오류 발생 시 자동으로 알림을 보냅니다.

## 사용 방법
알림 채널을 설정하면, 오류 시 즉시 알림을 받습니다.

## 주요 기능
- Slack, Email 알림
- 심각도 분류
- 알림 그룹화
- 에스컬레이션
