# 로컬 환경 설정

로컬 개발 환경을 자동으로 설정합니다.

## 사용 방법
프로젝트를 분석하여 필요한 도구를 설치하고 설정합니다.

- Docker Compose
- 가상 환경 설정
- 데이터베이스 시딩
- 환경 변수 설정
