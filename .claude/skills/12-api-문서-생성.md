# API 문서 생성

API 엔드포인트의 상세한 문서를 자동으로 생성합니다.

## 사용 방법
API 코드를 제공하면, OpenAPI/Swagger 형식의 문서를 생성합니다.

## 주요 기능
- OpenAPI 3.0 지원
- Swagger 문서 생성
- 요청/응답 예시
- 인증 방법 문서화
