# 테스트 결과 해석

테스트 결과를 분석하고 실패 원인을 설명합니다.

## 사용 방법
테스트 로그를 제공하면, 실패 원인과 해결 방법을 제시합니다.

## 주요 기능
- 실패 원인 분석
- 스택 트레이스 해석
- 수정 방향 제안
- 회귀 테스트 추천
