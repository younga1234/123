# 코드 리뷰 자동화

Pull Request를 자동으로 리뷰합니다.

## 사용 방법
PR을 생성하면, 자동으로 코드를 분석하고 피드백을 제공합니다.

## 주요 기능
- 정적 분석
- 베스트 프랙티스 검사
- 보안 스캔
- 자동 승인

## 사용 예시
이 skill을 사용하려면 Claude에게 관련 작업을 요청하세요.

예: "코드 리뷰 자동화 도와줘"

## 참고사항
- 이 skill은 개발 효율성을 높이기 위해 설계되었습니다
- 비개발자도 쉽게 사용할 수 있도록 자동화되어 있습니다
- 추가 질문이나 세부 조정이 필요하면 언제든지 요청하세요
