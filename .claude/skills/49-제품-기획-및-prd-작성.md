# 제품 기획 및 PRD 작성

제품 요구사항 문서(PRD)를 작성합니다.

## 사용 방법
제품 아이디어를 제공하면, 상세한 PRD를 작성합니다.

## 주요 기능
- 요구사항 정의
- 사용자 스토리
- 기능 명세
- 우선순위 설정
