# 데이터베이스 스키마 생성

데이터베이스 테이블 스키마를 자동으로 생성합니다.

## 사용 방법
데이터 모델을 설명하면, SQL 스키마를 생성합니다.

## 주요 기능
- MySQL, PostgreSQL 지원
- 인덱스 자동 설정
- 관계 정의
- 마이그레이션 파일 생성
