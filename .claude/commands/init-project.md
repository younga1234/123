프로젝트를 초기화하고 기본 구조를 생성해주세요.

다음 작업을 수행해주세요:
1. 프로젝트 유형 확인 (Node.js, Python, React, etc.)
2. package.json 또는 requirements.txt 생성
3. 기본 디렉토리 구조 생성
4. .gitignore 파일 생성
5. README.md 초안 생성
6. Git 저장소 초기화

사용자에게 프로젝트 유형을 먼저 물어보고 진행하세요.
