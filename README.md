# 🚀 Claude Code: 비개발자를 세계 최고의 개발자로

**완벽한 개발 환경 - 400개 이상의 자동화 도구**

<br />

## 📖 개요

이 프로젝트는 **비개발자도 전문 개발자 수준의 작업을 수행**할 수 있도록 설계된 완벽한 Claude Code 환경입니다.

### 🎯 포함된 내용

- **100개 Skills** - 재사용 가능한 지식 모듈
- **100개 Commands** - 즉시 실행 가능한 명령어
- **100개 Hooks** - 자동화 및 보호 시스템
- **100개+ Subagents** - 특화된 AI 전문가들

**총 400개 이상의 도구**가 당신을 지원합니다!

<br />

- ✅ 각 단계 상세 설명

## 🚀 빠른 시작

### 1. 새 프로젝트 시작하기

```bash
/init-project
```

프로젝트 유형을 선택하면 자동으로:
- 디렉토리 구조 생성
- 설정 파일 생성
- Git 저장소 초기화
- README 작성

### 2. 코드 작성하기

```bash
/write-function
```

원하는 기능을 설명하면:
- 코드 자동 생성
- 주석 자동 추가
- 테스트 자동 작성
- 사용 예제 제공

### 3. 에러 해결하기

```bash
/fix-error
```

에러 메시지를 붙여넣으면:
- 원인 자동 분석
- 해결 방법 제시
- 코드 자동 수정

## 🎯 주요 Commands

### 프로젝트 관리
- `/init-project` - 새 프로젝트 초기화
- `/quick-start` - 빠른 시작 가이드
- `/templates` - 프로젝트 템플릿

### 코딩 지원
- `/write-function` - 함수 자동 작성
- `/complete-code` - 코드 자동 완성
- `/refactor` - 코드 리팩토링
- `/optimize` - 성능 최적화

### 디버깅
- `/fix-error` - 에러 자동 수정
- `/debug` - 버그 찾기
- `/security-check` - 보안 체크

### 테스트
- `/write-test` - 테스트 작성
- `/run-tests` - 테스트 실행
- `/test-coverage` - 커버리지 확인

### Git
- `/git-commit` - 커밋
- `/git-branch` - 브랜치 생성
- `/git-conflict` - 충돌 해결

### 문서화
- `/generate-readme` - README 생성
- `/document-api` - API 문서
- `/changelog` - CHANGELOG

### 배포
- `/build` - 빌드
- `/deploy` - 배포
- `/docker` - Docker 설정
- `/ci-cd` - CI/CD 파이프라인

**전체 목록**: 100개 Commands 사용 가능

## 🎓 비개발자를 위한 가이드

### Q: 프로그래밍을 몰라도 되나요?
**A**: 네! 이 시스템은 비개발자를 위해 설계되었습니다.

### Q: 어떻게 시작하나요?
**A**:
1. `/templates` 입력
2. 원하는 프로젝트 유형 선택
3. 시스템이 모든 것을 안내합니다!

### Q: 에러가 발생하면?
**A**: `/fix-error` 입력하고 에러 메시지를 붙여넣으세요. 자동으로 해결됩니다!
